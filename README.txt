PROYECTO WEB — INVITACIÓN LOREANA & DANNY

Estructura:
invitacion_loreana_danny_proyecto/
├── index.html
├── style.css
├── script.js
└── images/
    └── (coloca aquí tus fotografías, logos o decoraciones)

index.html
- Contiene la estructura y textos de la invitación.

style.css
- Contiene colores, tipografías, tamaños, espacios, tarjetas y diseño responsive.

script.js
- Contiene el contador, animaciones de aparición y comportamiento del formulario RSVP.

images/
- Carpeta preparada para incorporar imágenes.
- Para usar una imagen, por ejemplo:
  <img src="images/foto.jpg" alt="Descripción">

Para visualizar:
1. Descomprime el proyecto.
2. Abre index.html en Chrome, Edge o Firefox.
3. Para editar, usa Visual Studio Code u otro editor.

Nota:
El formulario RSVP actualmente muestra una confirmación en pantalla, pero no envía
los datos a un servidor ni los guarda en una base de datos.
